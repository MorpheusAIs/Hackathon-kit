# Design system and ad drafts

## Step 1: Market look (20 min)
Look at 5–8 sites and ads the buyer already sees: competitors, the tools they use, the trade publications. For each, note palette, type, density, photo vs illustration, tone, and what feels trusted. Cite each URL.

## Step 2: Map the ideal setup
| Decision | Choose | Why (from Step 1 + the audience) |
|---|---|---|
| Position | familiar-but-better, or deliberate contrast | |
| Palette | 1 primary, 1 accent, 2 neutrals (hex), contrast ≥ 4.5:1 for text | |
| Type | 1 heading + 1 body font (free, e.g. Google Fonts) | |
| Imagery | real product screenshots > founder photos > illustration > stock | |
| Tone words | 3 | |
| Deck format | 16:9, one idea per slide, big numbers, ≤ 15 words per slide | |
| Ad formats | 1:1 and 9:16 static; 9:16 video | |
Judges usually reward clean, confident and concrete design. Avoid hype gradients and crypto visual clichés unless the buyer's market uses them.

## Step 3: Brand kit (`research/design.md`)
Name lockup (text is fine), palette with hex codes, fonts, the logo rule, a slide template description, the ad template, and 3 "do / don't" examples.

## Step 4: Ad drafts (`showcase/ad-drafts.md`)
For each of the top 3 hooks: one static concept (layout, headline placeholder, visual, call to action) in 1:1 and 9:16. Rough copy only. **Pass this file to `/direct-response`**, which writes the final copy. Then build the finals in Canva, or as HTML exported to PNG, using the brand kit.

Rules: label any AI-generated image. Use only real product screenshots for the product. No fake testimonials, no fake logos of customers.
